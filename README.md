# Interactive Dashboard

## Overview
This project is an interactive dashboard that visualizes data from a JSON and CSV file. It includes features such as data visualization, search functionality, sorting options, and user preferences storage.

## Features
- Data visualization using charts
- Search functionality across displayed data
- Sorting options for the data table
- Sidebar navigation for different views
- Local storage for user preferences (theme, view, filters)
- Animations and transitions for a polished user experience

## Setup Instructions
1. Clone the repository or download the files.
2. Open `index.html` in a web browser.

## Usage
- Use the sidebar to switch between the data table and chart views.
- Search for specific items in the data table using the search input.
- Click on the table headers to sort the data.

## Code Explanation
- The HTML structure includes a header, navigation, and main content area.
- The JavaScript code handles data loading, searching, sorting, and chart rendering using Chart.js.
- Local storage can be implemented to save user preferences for theme and view.
